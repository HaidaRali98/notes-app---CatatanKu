# CatatanKu

Aplikasi pencatatan berbasis Web Component yang terhubung ke
[Dicoding Notes API](https://notes-api.dicoding.dev/v2).

## Fitur

- Menampilkan, menambah, dan menghapus catatan
- Mengarsipkan dan memulihkan catatan
- Validasi formulir secara realtime
- Loading indicator dan pesan error
- Animasi dengan GSAP

## Teknologi

- JavaScript (Web Component, Fetch API)
- webpack dan html-webpack-plugin
- SweetAlert2 dan GSAP
- Prettier

## Cara menjalankan

1. Install dependensi:

npm install


2. Jalankan mode development:

npm run start-dev


3. Build untuk production:

npm run build
